# Changelog

## v1.0.2

- Fix: the release now includes `skills-starter-pack.plugin` (it was built but not uploaded in v1.0.1).

## v1.0.1

- New: **`skills-starter-pack.plugin`**, which installs all five skills in one step in the Claude desktop app.
- Claude install guide now leads with the one-file plugin install, and notes that Team and Enterprise admins can add the skills for a whole organisation.

## v1.0.0

First release of the Sope Skills Starter Pack.

- **Meeting Transcript → Summary & Actions:** summary, decisions, action table with owners and due dates.
- **Voice & Tone Matcher:** builds a reusable voice profile from your own emails and drafts in your voice.
- **Document → Executive Summary:** a one-page plain-English brief from long reports, contracts and policies.
- **Inbox Triage & Reply Drafts:** thread summary, the ask and deadline, and 2 to 3 reply options at different tones.
- **Plain-English Rewriter:** simplifies dense text, or structures rough notes into a document.
- Install guides for Microsoft 365 Copilot, Claude, Claude Code and ChatGPT.
